# Model card: event classifier

**Intended use.** Assign one of ten event classes (Macroeconomic, Geopolitical, Credit Event, M&A and Corporate Action, Product and Strategy, Earnings and Guidance, Legal and Regulatory, Operational and ESG, Management and Governance, Other) with a subtype and confidence.
**How.** SEC 8-K item codes are authoritative labels (1.03 bankruptcy, 1.05 cyber incident, 2.02 results, 4.02 restatement, 5.02 officer change). Other text uses weighted, title-boosted regular-expression rules. At event level the class is a credibility-weighted vote across the story's reports; commentary (Other) neither wins nor dilutes. A short seller's fraud report is MANAGEMENT_GOVERNANCE/FRAUD_ALLEGATION, mapped to the Adani-Hindenburg analog.
**Evaluation.** Gold-set accuracy vs the majority class in `make results` (in-sample for the rules: a sanity check). On real GDELT news, rules-v0 missed the SVB window because real headlines ("Silicon Valley Bank Startups Panic", "California Regulator Shuts Silicon Valley Bank") fell into Other. rules-v1 adds bank-crisis vocabulary next to "bank" and regulators closing or taking control of a bank; the SVB real-news row is therefore no longer out-of-sample, and this is stated wherever it is reported. The Adani and control windows give identical results under v0 and v1.
**Limitations.** Rules miss novel phrasing; this is the weakest component on real headlines. Planned upgrade: an embedding classifier trained on 8-K weak labels and labelled headlines.
